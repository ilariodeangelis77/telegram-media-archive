## Using in Obsidian

Open this folder as a vault, or copy its Markdown folders into an existing vault. The catalogue uses ordinary Markdown, YAML properties and wiki links; no plugin is required. If importing, keep the internal folder structure together. All 773 images are copied into `Images/` inside this vault. Image links and embeds use vault paths, so they travel with the folder. Source notes display their image; media notes preview their first source and link to every identified source. [[Gallery]] and [[Review]] include image thumbnails. Click an image link to open the full-resolution file. Original Telegram message links still use the external HTML archives.

## Archive and source links

The original source images remain at `[percorso locale omesso]`; byte-identical copies are stored here in `Images/`, grouped by chat, with loose images in `Images/Loose/`. This vault can now carry its own image sources when moved or copied. The copies are on the same drive; keep a separate backup of the whole vault as well. Telegram HTML message links still depend on their external archive locations. `_processing/image_assets_manifest.json` records the original paths and hashes. The Markdown before this update is preserved in a ZIP under `_processing/backups/`.

## Extraction quality

These are extracted names, not reviews, personal endorsements or read/listened/watched history. `status: unreviewed` is left for your use. Titles were read from covers/charts, recognized from distinctive covers or taken from original Telegram captions. Credits are only populated when identifiable; unknown credits stay empty. Album cover recognition and ambiguous edition information should be checked against the linked source before treating them as verified bibliographic records. No release dates, genres, synopses, or other enrichment was invented. A few web checks are recorded in the relevant identification notes.

Repeated works are merged, with all identified image sources retained. Artist-only charts have individual artist notes. Multi-work charts have separate notes for each extracted title. General ideology/psychology diagrams and untitled art are retained as images, not expanded into hundreds of speculative media notes. Unknown or obscured titles are listed in [[Review]] with OCR where useful.

The `_processing` folder contains local extraction data and reproducible scripts. `build.py` regenerates the catalogue and overwrites generated notes; do not rerun it after adding personal edits without preserving those edits first. No original archive file was modified.
